# Quantization

本文约束 PTQ、QAT、INT8、INT4 和 FP16 等量化工作的记录与验证方式。V0.1 不预设任何模型或平台的量化能力。

## 基本原则

- 在量化前建立可复现的浮点基线。
- 校准与评估必须使用明确版本的数据集和一致的预处理。
- 记录逐层或逐节点配置、排除策略、对称性、粒度和数据类型。
- 编译成功不代表量化正确，必须比较输出正确性和任务精度。
- 性能优化必须同时检查精度是否退化。

## Calibration 记录

- 数据来源与 License；
- 数据版本、样本数量和选择规则；
- 输入形状、颜色空间、归一化和张量布局；
- 随机种子或确定性抽样方式；
- 校准工具、版本、命令和日志；
- 数据隐私与可分发边界。

## 量化实验记录

- 模型版本和输入模型校验信息；
- 目标平台、SDK、Compiler 和 Runtime；
- PTQ 或 QAT 方法；
- 精度类型和算子级配置；
- 浮点、量化模拟和真实平台结果；
- 精度差异、性能差异及异常分析。

没有真实实验结果的字段统一写 `TBD`，不得填入推测值。
